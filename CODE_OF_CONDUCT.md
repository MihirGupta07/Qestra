# Code of Conduct

We want Qestra Orchestrator to be a respectful, practical, and welcoming project.

## Expected Behavior

- Be kind and direct.
- Assume good intent, but accept corrections gracefully.
- Keep discussions focused on the work.
- Make room for beginners and experienced contributors alike.

## Unacceptable Behavior

- Harassment, threats, or personal attacks.
- Discriminatory language or behavior.
- Publishing private information without permission.
- Repeatedly derailing technical discussions.

## Reporting

If you need to report an issue, open a private security advisory on GitHub or contact the maintainers through the project owner account.

Reports will be reviewed with care and handled as privately as practical.
